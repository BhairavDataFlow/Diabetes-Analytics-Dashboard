🔍 Overview

This Power BI dashboard visualizes diabetes-related metrics using healthcare data. It helps identify high-risk patient groups based on BMI, glucose level, age, and other clinical indicators.

📊 Key Features

KPI cards for BMI, Glucose, and Pregnancy averages

Interactive slicers by Age and BMI Category

Donut chart showing diabetes risk levels

Line and bar charts comparing Glucose & Blood Pressure by Age

Clean professional UI with “Sweet Spot: Diabetes Analytics” theme

🧠 Tools Used

Power BI Desktop

Excel (Data Source)

DAX & Power Query for measures and transformations

📈 Insights

Majority of patients fall into Obese BMI category (~61%)

High glucose spikes occur between ages 40–60

Diabetes risk increases with age and BMI
